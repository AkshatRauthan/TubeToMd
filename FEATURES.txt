12. LLM & AI INFRASTRUCTURE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- Fast LLM — Llama 3.1 8B           Speed tier for translation and structured data

- Background Key Reactivation        10 s interval timer reactivates cooled-down rate-limited keys
- Runtime Key Management             Add/remove API keys without restarting the server
